# The project's goal, and the work that moves it

Part of the set's protocol, whose core is `protocol.md`: the same in every
project, and it wins over a project's restatement.
What the project is getting to in this period, how that is measured, and what
every level of work below it owes the measurement.

**A project's goal is its key results, and every piece of work names the one it
moves.** The direction is one objective in the owner's words: what becomes
possible, for whom, in a sentence a person would repeat. Under it stand two or
three key results, never more — each measured on the product or on its users,
in a number, with the value that counts as reached and the date the period
closes. A key result is a target, not a status: what is true today belongs to
the record, and a target is never moved to meet what happened. Where the owner
states no number, the key results are proposed as the smallest set that would
show the objective reached, and the owner accepts, corrects or refuses them. A
goal nobody set is never written as an agreed one, and a project that has none
yet says so in one line instead of inventing one: the next planning
conversation that can establish a goal does, and until then work follows the
protocol's own lanes.

**Where the goal is kept.** In the vision's `## Success signal`, in the shape
the journeys and principles already use there — the objective is the vision's
`## Outcome`, in one sentence, and under it:

```
Due: <YYYY-MM-DD>
K1: <what is measured> — <the value that counts as reached>
K2: <what is measured> — <the value that counts as reached>
```

One file holds it, where a run reads it: the vision by default, the roadmap or
a product document of the project's own where the vision is the wrong place for
a number. Where a key result is a belief rather than a number someone already
watches, it is written as [product.md](product.md)'s hypothesis, with the
measure and the threshold that would confirm it, and the key result names that
hypothesis. When the period closes, what happened is read onto the record
first, and the next period's key results are written from it — the closed ones
are not edited into the new period.

**Every level names the key result it moves.** A charter's outcome line carries
`Moves: K1, K2`, and so does each stage and each leaf under it: one line, the
key results that outcome or that piece of work changes, in the same one-line
shape the other facts a body carries use. Where a stage
carries work for one key result and a task within it for another, the task's own
line is the one that counts. The link is read from the record, never inferred
from a title.

**Work that moves no key result is not first priority.** It is not forbidden:
it takes a later milestone, the ideas lane with its review date, a deferred item
under its feature, or a question for the owner where nobody can say what it
serves. What it never does is reach the front of the queue by being interesting,
urgent in the agent's own reading, or cheap. The exceptions stay the protocol's
own, and each names what it protects: a repair a landing waits on and upkeep of
the installation are charged to the work they serve, and a fault that costs a
person something now keeps the urgency **A finding that does not fit is decided,
not parked** gives it.

**A contribution is a claim, and a claim carries its evidence.** What the work
changes in the number, how that is observed, and what would show it moves
nothing. Where the contribution cannot be established from the documents, the
tracker or the owner's words, it is not invented: the item says the link is
unknown, the owner is asked, and the answer is written where the item is read.
A key result named to qualify a piece of work is the measurement changed to suit
the answer.

**The queue and the breakdown follow the key results.** Grooming's slice is the
work that moves this period's key results, and a finding is on the queue when it
moves one or protects one. The breakdown cuts a result until each piece is one
short pull request and hours of agent work, by the protocol's **Levels**: a piece
bigger than that is cut before it is filed, and one that cannot be cut without
choosing between key results is the owner's decision, not the breakdown's.
