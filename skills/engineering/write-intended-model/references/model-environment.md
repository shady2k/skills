# Model environment

## Model and engine locations

- `$MODELDIR` is the repository's model folder, `model/` beside the code;
  where the engine reads the model from another folder, the engine's section
  in the product's agent doc names it.
- `$ENGINE` is a checkout of the engine, the product's own program that
  serves the product's wiki, makes its layout and runs the model's check;
  the engine's section in the product's agent doc names it. The check is how
  the engine proves a written model.
- Where no engine is installed, still write every file required by the
  current skill, including its model and review report. Run no check and tell
  the person the model stands unchecked, and how to install the engine.
